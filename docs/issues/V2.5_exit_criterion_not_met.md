## Root causes / blockers

1. **Extraction, not evidence:** chemistry 1.000 reachable but 0.455 measured; format similar.
2. **Evidence:** cell header outside window; 7 unreachable temperatures need owner/SI re-extraction.
3. **Metric power:** only 3 repeats — 0.000 false extraction cannot be demonstrated.
4. **Gate tension:** downstream applicability rubric (V2.1) and roadmap D9 require reliable conditions; V2.6 stays hard-gated.

## Research notes (public sources)

- Multi-stage source-tracked extraction (arXiv:2510.05142): F1 0.869 → 0.959 on materials IE; realistic here +0.02–0.06.
- SafePassage (arXiv:2510.00276): span aligner + NLI, up to 85% hallucination reduction; small encoder beat LLM grader.
- Valid per-field selective risk control (arXiv:2608.14639): document-level splits, design effect 1.84–2.45; no test tuning.
- Verbalised confidence is overconfident — do not use for gating.
- Table/contextual retrieval (Anthropic Contextual Retrieval; arXiv:2605.00318; arXiv:2506.10380) supports short labelled verbatim header context; richer windows may hurt ("Lost in the Middle", arXiv:2307.03172).
